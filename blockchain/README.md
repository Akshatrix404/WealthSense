# blockchain

`TransactionLedger.sol` — a single, deliberately minimal Solidity contract
that anchors a cryptographic hash of each WealthSense transaction on the
Polygon Amoy testnet, per user address. One contract, not the originally
five-contract plan — scoped down intentionally (see the report's
tech-stack justification section).

## Setup

```bash
cd blockchain
npm install
cp .env.example .env
# edit .env: set AMOY_RPC_URL and AMOY_PRIVATE_KEY (testnet-only wallet,
# funded from https://faucet.polygon.technology -- select "Amoy")
```

## Compile and test

```bash
npx hardhat compile
npx hardhat test
```

**Note on how this was verified during development:** this sandbox's
network egress blocks `binaries.soliditylang.org`, which is where
Hardhat normally downloads the solc compiler binary from — so
`npx hardhat compile` couldn't run directly in that environment. It was
verified instead by compiling via the `solc` npm package directly (npm
registry access is allowed) and manually placing the resulting artifact
where Hardhat expects it, then running the real test suite against that
artifact. All 3 tests passed against a real local Hardhat Network
instance. **On a normal machine with unrestricted internet access,
`npx hardhat compile` will work directly** — this workaround was a
sandbox-specific constraint, not a project limitation.

Expected output:
```
  TransactionLedger
    ✔ 1. deploys successfully with a valid contract address
    ✔ 2. adds a transaction and confirms it's stored correctly
    ✔ 3. returns the correct array for the correct address, and an empty array for an unused address

  3 passing
```

## Deploy to Polygon Amoy

```bash
npx hardhat run scripts/deploy.js --network amoy
```

This prints the deployed contract address and a Polygonscan link. **Save
the address** — the FastAPI bridge (`../backend/`) needs it, along with
the ABI from `artifacts/contracts/TransactionLedger.sol/TransactionLedger.json`
(generated by `npx hardhat compile`).

**This step was not run against the live Amoy network during
development** — it requires a real, funded testnet wallet's private key,
which isn't something to generate or fund from an automated environment.
Run it yourself once your `.env` is set up.

## Contract interface (v2)

```solidity
function addCommitment(bytes32 commitment) external returns (uint256 index);
function getLedger(address user) external view returns (Entry[] memory); // (commitment, timestamp)
function getLedgerLength(address user) external view returns (uint256);
function getEntry(address user, uint256 index) external view returns (Entry memory);
```

Only an opaque 32-byte HMAC commitment and the block timestamp are stored. v1 stored the plaintext
amount and category next to an unsalted hash, which is why it was replaced. `contracts/experimental/MerkleAnchor.sol`
is used only for the gas comparison (`scripts/gas_experiment.js`).

On machines that cannot download the Solidity compiler, use `--config hardhat.offline.config.js`
(it compiles with the npm `solc` package).
